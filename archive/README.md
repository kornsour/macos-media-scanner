# Archive

This folder holds historical and superseded documentation and records for this project — things like old design notes, retired plans, or snapshots of past project state that are no longer accurate.

**Contents here are historical only.** They reflect decisions, plans, or state from a specific point in the past, and may no longer match how the project actually works today. Do not use anything in this folder to understand the current state of the project, and do not use it as a reference when making new changes.

Contributors and coding agents (including Claude Code) should treat everything under `archive/` as background context at most, never as current truth. For up-to-date information, refer to the top-level `README.md`, `CLAUDE.md`, and the source code itself.
